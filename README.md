## Setup

The notebooks run in Google Colab as they are (use the badges in each week's README). To run them locally:

```bash
git clone -b 26f_ymls_uz https://github.com/girafe-ai/ml-course.git
cd ml-course
poetry install   # Python 3.11, versions pinned in poetry.lock (includes ipykernel)
```

Then choose the Poetry environment as the kernel in VS Code or Jupyter.
