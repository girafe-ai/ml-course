# Week 2: Maximum Likelihood + Linear Regression

Lecture slides: [`ml-basic_lect02_mle_linear_regression.pdf`](ml-basic_lect02_mle_linear_regression.pdf)

The lecture covers the probability the course needs (distributions, expectation and variance, the normal
distribution, i.i.d. samples), maximum likelihood estimation with a coin and a normal distribution worked out by
hand, why squared error is the loss for regression (normal noise plus maximum likelihood gives least squares,
Laplace noise gives absolute error), linear models, and linear regression: the normal equations, gradient
descent, feature scaling and regression metrics.
