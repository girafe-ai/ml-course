# Week 4: Linear Classification + Logistic Regression

Lecture slides: [`ml-basic_lect04_logistic_regression.pdf`](ml-basic_lect04_logistic_regression.pdf)

The lecture moves from predicting a number to predicting a class. It starts with a linear classifier: the
boundary as a hyperplane, the margin, and the losses that stand in for the count of mistakes. Then logistic
regression: odds and the sigmoid, the log-loss from maximum likelihood, its gradient, training by gradient
descent and by Newton's method. The second half is about reading the weights as changes in the odds, what
happens when the classes can be split perfectly and how the L2 penalty fixes it, curved boundaries from
polynomial features, and more than two classes with one-vs-rest, one-vs-one and softmax regression.
