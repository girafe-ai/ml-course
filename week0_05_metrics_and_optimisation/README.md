# Week 5: Classification Metrics + Optimisation Methods

Lecture slides: [`ml-basic_lect05_metrics_optimisation.pdf`](ml-basic_lect05_metrics_optimisation.pdf)

The lecture has two halves. The first is about measuring a classifier: why accuracy says little when a class
is rare, the confusion matrix, precision, recall and F1, how the threshold trades one kind of mistake for the
other and how to choose it from their costs, ROC and precision-recall curves, metrics for more than two
classes, and class weights. The second half is about training: gradient descent and its step size, the
condition number and why features are scaled, momentum, RMSProp and Adam, and mini-batch SGD.
